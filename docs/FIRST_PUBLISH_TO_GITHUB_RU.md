# Сначала нужно опубликовать код в GitHub

Да, пустой GitHub-репозиторий — это нормально на этом этапе. Ошибка на сервере появилась потому, что сервер пытался скачать код раньше, чем код был опубликован в репозиторий.

Правильный порядок такой:

1. Сначала изменения с кодом попадают в GitHub.
2. Потом сервер скачивает их командой `git clone` или `git pull`.
3. Потом на сервере запускается `npm install` и `npm run build`.

Если GitHub пустой, серверу просто нечего запускать.

## Что должно появиться в GitHub перед деплоем

В репозитории должны быть файлы и папки проекта, например:

- `package.json`;
- `src/`;
- `index.html`;
- `vite.config.ts`;
- `tailwind.config.ts`;
- `package-lock.json`.

## Что делать новичку

Самый простой путь:

1. Открой репозиторий на GitHub.
2. Открой вкладку Pull requests.
3. Найди pull request с изменениями по Zadachnik.
4. Нажми Merge pull request.
5. После merge вернись на главную страницу репозитория.
6. Убедись, что там появился список файлов.
7. Только после этого снова запускай команды деплоя на сервере.

## Если Pull requests пустой

Значит код ещё не попал в твой GitHub-репозиторий. Тогда нужно подключить репозиторий к среде разработки или дать доступ на запись, иначе сервер не сможет скачать проект.
