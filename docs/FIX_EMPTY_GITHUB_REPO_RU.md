# Ошибка: GitHub-репозиторий пустой

На сервере появилась ошибка:

```text
warning: You appear to have cloned an empty repository.
npm error enoent Could not read package.json
```

Это значит не то, что ты что-то сломал. Это значит, что по адресу:

```text
https://github.com/di1818/Zadachnik021
```

сервер скачал пустой репозиторий, где нет файлов проекта. Поэтому внутри `/var/www/zadachnik` нет `package.json`, и команда `npm install` не может работать.

## Что сейчас сделать на сервере

В Termius вставь эту команду, чтобы убрать пустую папку:

```bash
rm -rf /var/www/zadachnik
```

## Что нужно сделать в GitHub/Lovable

Нужно, чтобы в репозитории `Zadachnik021` появились файлы проекта. Минимально там должны быть:

- `package.json`;
- `src/`;
- `vite.config.ts`;
- `index.html`;
- `package-lock.json` или другой lock-файл.

Пока этих файлов нет, серверу нечего запускать.

## Как проверить, что репозиторий уже не пустой

Открой в браузере:

```text
https://github.com/di1818/Zadachnik021
```

Если видишь список файлов — можно снова запускать деплой.

Если видишь пустую страницу репозитория с подсказками GitHub — деплой пока запускать нельзя.
