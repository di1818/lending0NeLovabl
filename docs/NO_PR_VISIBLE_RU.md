# Почему в GitHub не видно Pull Request

Если на странице GitHub во вкладке Pull requests пусто, значит изменения из этой рабочей среды ещё не попали в твой GitHub-репозиторий.

Это не твоя ошибка. Сервер и GitHub видят только то, что реально опубликовано в репозитории `di1818/Zadachnik021`. Если репозиторий пустой, вкладка Pull requests тоже может быть пустой.

## Что делаем дальше

Чтобы не мучить тебя GitHub на нулевом уровне, можно идти проще:

1. Сначала поднять первую версию задачника прямо на сервере через Termius.
2. Потом отдельно разобраться с GitHub и сделать нормальную синхронизацию кода.

Так ты быстрее увидишь работающий результат в браузере.

## Важный вывод

Пока GitHub пустой, команды `git clone` и `git pull` для проекта использовать нельзя. Они будут снова скачивать пустую папку.
