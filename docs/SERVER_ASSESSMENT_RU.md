# Анализ сервера 80.74.30.154

Дата анализа: 2026-06-15.

## Короткий вывод

Сервер можно использовать для задачника рядом с Telegram-ботом, но аккуратно.

Лучший вариант для первого запуска:

- frontend задачника держать на этом VDS;
- базу данных, авторизацию и файлы хранить в Supabase;
- не ставить тяжёлый отдельный backend и PostgreSQL на VDS на первом этапе;
- не трогать сервис `ai-gpt-bot.service` и папку `/opt/ai_gpt_bot`.

## Что уже есть на сервере

По выводу проверки видно:

- операционная система: Ubuntu 24.04.4 LTS;
- памяти: около 1.8 GB RAM;
- свободного диска: около 34 GB из 40 GB;
- Nginx уже работает на портах 80 и 443;
- Apache работает локально на `127.0.0.1:8080`;
- ispmanager использует порты 1500/1501;
- MySQL уже установлен и работает на `127.0.0.1:3306`;
- Telegram-бот запущен как `ai-gpt-bot.service`;
- код бота находится в `/opt/ai_gpt_bot`;
- webhook бота работает через Python на `127.0.0.1:8088`.

## Что нельзя трогать

Чтобы не сломать Telegram-бота, нельзя без отдельной необходимости менять или удалять:

- `/opt/ai_gpt_bot`;
- `ai-gpt-bot.service`;
- порт `8088`;
- общие настройки Nginx, пока не понятна текущая схема сайтов;
- MySQL, если он используется ispmanager или ботом.

## Почему Supabase лучше на старте

На сервере всего 2 GB RAM, часть памяти уже занята системными сервисами, ispmanager, Nginx, Apache, MySQL и Telegram-ботом.

Поэтому на первом этапе безопаснее не ставить рядом ещё PostgreSQL, backend, файловое хранилище и очереди. Supabase закроет:

- логин/пароль;
- базу задач;
- хранение файлов;
- права доступа;
- будущую возможность дать доступ друзьям или клиентам.

## Следующий безопасный шаг

Нужно понять, какие сайты уже настроены в Nginx/ispmanager и куда можно положить frontend задачника.

Скопируй в Termius одну команду:

```bash
printf '\n=== NGINX SITES ===\n'; find /etc/nginx -maxdepth 3 -type f \( -name '*.conf' -o -name 'default' \) -print; printf '\n=== NGINX SERVER NAMES ===\n'; grep -R "server_name\|root\|proxy_pass" /etc/nginx/sites-enabled /etc/nginx/conf.d 2>/dev/null || true; printf '\n=== WWW DIRS ===\n'; find /var/www -maxdepth 3 -type d -print 2>/dev/null; printf '\n=== BOT SERVICE ===\n'; systemctl cat ai-gpt-bot.service; printf '\n=== DONE ===\n'
```

После выполнения пришли мне весь вывод.
